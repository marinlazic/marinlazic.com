# X post

Where it goes: Marin's X profile. One post, and an optional thread.

Limits
- 280 characters for the single post. Write to 280 even if the account allows more. Short posts get read.
- A thread is 3 to 7 posts, each under 280 characters, each able to stand alone.
- No hashtags. No emoji. No link in the first post of a thread; the link goes in the last post, or in a reply.

Shape, single post
- The claim in one or two sentences. Specific. Plain.
- If there is room, one fact or the action.

Shape, thread
1. The claim. Must work alone, because most people only see this one.
2. The mechanism, one post.
3. The proof on record, one post.
4. What most people get wrong, one post.
5. The action for this week, one post.
6. The call to action with the link, one post.

Writing notes
- Write five single post variants, each a different cut of the core: claim, proof, action, objection, the sharpest line. Marin posts them across the week.
- Lines break only between thoughts. No "1/" numbering, the platform threads them.
- The credential appears once, in the proof post, as fact.
- Say nothing you would not say to a client's face.

File header block
```
Channel: X post
Paste into: X, new post
Attach: none, or one image if the thread needs the chart
Check before posting: each post under 280 characters, link only in the last post
```
Then: Single posts 1 to 5 with character counts. Then the thread, numbered, with counts.
