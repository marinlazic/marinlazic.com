# Substack Note

Where it goes: the Notes tab on Substack. Short, feed style, no title.

Limits
- 300 to 700 characters. Notes can be longer, but short ones travel.
- No title. No subject. Plain text with line breaks.
- One link at most, and only if the note is pointing at the newsletter. Most notes carry no link.

Shape
1. The claim or the single sharpest line from the core, standing alone.
2. Two to five short lines that earn it: the mechanism, or the fact on record.
3. Optional one line action.

Writing notes
- A Note is one thought. Not a summary of the newsletter.
- It should read fine with no context. Someone who has never heard of Marin should get the point.
- Write three variants. Marin posts them across the week. Each takes a different angle from `00-core.md`: the claim, the proof, the action.
- No "New post is live". If a Note points at the newsletter, it says what the newsletter argues and then the link.

File header block
```
Channel: Substack Note
Paste into: Substack, Notes
Attach: none
Check before posting: reads as a complete thought with no context
```
Then three notes, labelled Note 1, Note 2, Note 3, with the angle of each in one line.
